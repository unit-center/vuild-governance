# VUILD

**VUILD는 IT 커뮤니티 운영진의 네트워크입니다.** 이름은 Value Build에서 유래하며, 영문 VUILD, 국문 「빌드」로 표기합니다.

## 설립 배경

VUILD는 커뮤니티를 만드는 사람들을 위한 커뮤니티입니다.

인재들은 성장하기 위해 커뮤니티에 모이지만, 정작 커뮤니티를 지탱하는 운영진의 경험과 지식은 계승되지 못하고 흩어져 왔습니다. VUILD는 그 경험을 공동의 자산으로 만들기 위해 존재합니다.

## 설립 목적

커뮤니티 운영의 경험과 지식을 공동의 자산으로 축적하고, 커뮤니티의 안정적 운영과 지속가능한 구조를 도와 인재들이 성장할 수 있는 생태계에 기여합니다.

## 활동 방향

흩어져 있던 커뮤니티 운영의 경험과 지식을 모아 정리하고 공유합니다. 쌓인 지식은 운영을 고도화하는 프로그램으로 이어, 한 사람의 경험이 그 사람과 함께 사라지지 않게 합니다.

운영진이 서로 만나는 자리를 정기적으로 엽니다. 혼자 판단해야 했던 문제를 같은 일을 하는 사람과 나누는 것이, 운영의 지식이 가장 빠르게 쌓이는 길이기 때문입니다.

커뮤니티의 정보를 등록해 공개하고, 운영진이 해 온 활동은 기록으로 남겨 증명할 수 있게 합니다. 어떤 커뮤니티가 어디서 무엇을 하고 있는지 찾을 수 있어야 하고, 운영진이 쌓은 활동도 이력으로 설명될 수 있어야 하기 때문입니다.

커뮤니티와 기업·기관을 연결합니다. 커뮤니티가 필요한 자원에 닿고, 기업·기관이 커뮤니티를 제대로 찾을 수 있도록 중간에서 잇습니다.

## 성격

- **비영리입니다.** 운영진 개인과 등록 커뮤니티에게는 회비를 받지 않습니다. 후원사 회비 등 모든 수입은 위 목적을 위해서만 사용합니다.
- **정치·종교적 중립을 지킵니다.** 정당, 정치인 후원회, 선출직 후보와 그 캠프로부터 후원을 받지 않으며, 특정 정당이나 후보를 지지하거나 반대하지 않습니다. 특정 종교의 교리를 전파하지 않습니다. 공공기관·행정기관과의 협력은 이에 해당하지 않습니다.
- **등록 커뮤니티의 상위 기구가 아닙니다.** 등록 커뮤니티를 대표하거나 지휘하지 않습니다.

## 구성원

| 구분 | 설명 |
|---|---|
| **커뮤니티 운영진** | IT 커뮤니티를 운영한 경험이 있는 개인 회원 |
| **VO** (VUILD Officer) | VUILD의 프로그램을 기획하고 운영하는 사람 |
| **Alumni** | 수료하여 활동을 마친 VO. 활동 기록을 유지합니다 |
| **후원사** | VUILD를 후원하는 기업·기관 |
